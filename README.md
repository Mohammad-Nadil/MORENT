# 🚗 Morent - Car Rental Website

Morent is a modern and fully responsive car rental web application built with React.js and Tailwind CSS.  
The project focuses on clean UI/UX, smooth animations, and a modern dashboard experience for users who want to rent cars online.

---

## ✨ Features

- 🚘 Browse and explore rental cars
- 🔍 Detailed car information page
- ❤️ Favorite cars functionality
- 🛒 Rent flow with payment page
- 📱 Fully responsive design
- 🎬 Smooth animations using Framer Motion
- 📦 State management with Redux Toolkit
- 🧭 Nested routing with React Router DOM
- 📊 Modern dashboard UI
- ⏫ Scroll to top on route change
- 🌙 Clean and modern UI inspired by real-world SaaS dashboards

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- React Router DOM
- Redux Toolkit
- Framer Motion
- React Icons
- React Hot Toast

## ⚡ Installation

```bash
# Clone the repository
git clone https://github.com/your-username/morent.git

# Go to project folder
cd morent

# Install dependencies
npm install

# Start development server
npm run dev
```
